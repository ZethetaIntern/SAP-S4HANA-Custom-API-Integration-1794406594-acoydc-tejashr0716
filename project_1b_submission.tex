\section{2. Architecture Overview}
The integration pipeline follows an event-driven extract-transform-load (ETL) pattern:
\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
    \item \textbf{Extraction:} Consumes SAP S/4HANA OData services (\texttt{A\_JournalEntry}, \texttt{A\_SupplierInvoice}, \texttt{A\_CustomerInvoice}) supporting \texttt{\$top}, \texttt{\$skip}, and delta timestamps.
    \item \textbf{Resilience:} A 3-state Circuit Breaker (\texttt{CLOSED}, \texttt{OPEN}, \texttt{HALF\_OPEN}) protects against cascading ERP timeouts. Poison pill payloads are isolated into an in-memory Dead-Letter Queue (DLQ).
    \item \textbf{Transformation:} Translates ERP posting keys (\texttt{SHKZG} `S'/`H') into normalized double-entry debit/credit streams while verifying mathematical reconciliation.
    \item \textbf{Security:} Enforces OAuth 2.0 token validation and HMAC-SHA256 payload integrity signatures with a strict 300-second timestamp drift limit.
\end{itemize}
